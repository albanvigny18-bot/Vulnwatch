# Sources de données et mentions

VulnWatch (code sous licence MIT, voir `LICENSE`) **assemble des données publiques**. Chaque source reste soumise à ses propres conditions d'utilisation.

| Source | Utilisation dans VulnWatch | Conditions |
|---|---|---|
| **NVD**, National Vulnerability Database (NIST) | CVE, scores CVSS, produits, références | Données publiques du gouvernement américain. *This product uses the NVD API but is not endorsed or certified by the NVD.* |
| **CISA KEV** (Known Exploited Vulnerabilities) | Failles exploitées activement | Données publiques de la CISA |
| **CISA Vulnrichment** | Décisions SSVC, produits et versions affectés | Dépôt public de la CISA |
| **CVE.org** (CVE Program) | Enregistrements CVE (secours) | Conditions d'utilisation du programme CVE |
| **FIRST EPSS** | Probabilité d'exploitation | Gratuit, citation de FIRST demandée |
| **GitHub Security Advisories** | Paquets open source touchés, versions corrigées | Licence CC-BY 4.0 |
| **Metasploit Framework** (Rapid7) | Existence d'un module d'exploitation | Licence BSD |
| **Nuclei templates** (ProjectDiscovery) | Existence d'un modèle de détection | Licence MIT |
| **Exploit-DB** (OffSec) | Existence d'une preuve de concept publique | Conditions d'Exploit-DB |

VulnWatch n'affiche que des **métadonnées** (identifiant, nom du module, numéro EDB). Il ne redistribue aucun code d'exploitation.

**Avant tout usage commercial**, vérifie les conditions à jour de chaque source. Certaines demandent une attribution, d'autres limitent la redistribution ou l'usage commercial.

**Avertissement.** VulnWatch est un outil d'aide à la décision, fourni « tel quel ». Les priorités sont calculées automatiquement à partir de données publiques qui peuvent être incomplètes ou en retard. Elles ne remplacent pas l'analyse d'un professionnel ni les avis officiels des éditeurs.
